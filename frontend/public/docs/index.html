Keys2API 文档

引言

Keys2API 是一个 AI 模型 API 聚合服务，兼容 OpenAI、Anthropic Claude、Google Gemini 等主流大模型 API 格式，让你可以通过统一的接口访问多种 AI 模型。

核心特性

  • 统一接口：支持 OpenAI、Claude、Gemini 三大格式，一个 Key 搞定所有模型
  • 丰富模型：GPT、Claude、Gemini、DeepSeek、Qwen、GLM 等数百种模型
  • 图像生成：支持 DALL·E、GPT Image 等图像生成模型
  • 高可用性：多节点负载均衡，自动故障转移
  • 灵活计费：按 token 计费，支持分组定价
  • 实时流式：全面支持 SSE 流式输出
  • 函数调用：支持 Function Calling 和结构化输出
  • 视觉理解：支持图片识别和图文混合对话
Base URL

所有 API 请求的基础地址为：https://keys2api.com

快速开始

1. 注册并获取 API Key

  1. 访问 Keys2API 控制台 注册账号
  2. 在「API 密钥」页面创建新的 API Key
  3. 选择合适的分组（不同分组对应不同的模型和价格）
  4. 复制生成的 Key（格式：sk-xxxx）

2. 发起第一次请求

使用 cURL 发送一个简单的聊天请求：

curl https://keys2api.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-你的KEY" \
  -d '{
    "model": "gpt-4o",
    "messages": [{"role": "user", "content": "你好，介绍一下你自己"}]
  }'
Windows 环境下的写法

PowerShell（推荐）：

$body = @{
    model = "gpt-4o"
    messages = @(@{role="user"; content="你好，介绍一下你自己"})
} | ConvertTo-Json -Depth 5

curl.exe https://keys2api.com/v1/chat/completions `
  -H "Content-Type: application/json" `
  -H "Authorization: Bearer sk-你的KEY" `
  -d $body

CMD（命令提示符）：

curl https://keys2api.com/v1/chat/completions ^
  -H "Content-Type: application/json" ^
  -H "Authorization: Bearer sk-你的KEY" ^
  -d "{\"model\":\"gpt-4o\",\"messages\":[{\"role\":\"user\",\"content\":\"你好\"}]}"

提示：PowerShell 中 curl 是 Invoke-WebRequest 的别名，必须使用 curl.exe 调用真正的 curl。

from openai import OpenAI

分组说明

Keys2API 通过「分组」机制来区分不同级别的模型和定价。创建密钥时可以选择绑定到特定分组，从而控制该密钥能访问哪些模型及对应价格。

提示

不同分组对应不同的模型列表和价格倍率，请根据你的使用场景选择合适的分组。详情请参考 价格页面。

密钥（API Key）管理

  1. 登录控制台，进入「密钥」页面
  2. 点击「添加密钥」，设置名称、选择分组、设置额度
  3. 创建成功后复制 Key，妥善保存
  4. 可随时修改额度、重置 Key、或删除密钥

OpenAI Chat API

兼容 OpenAI Chat Completions API 格式，支持所有 OpenAI 模型及以 OpenAI 格式接入的其他模型。

基础对话（非流式）

POST /v1/chat/completions
curl https://keys2api.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-你的KEY" \
  -d '{
    "model": "gpt-4o",
    "messages": [
      {"role": "system", "content": "你是一个有帮助的助手。"},
      {"role": "user", "content": "什么是量子计算？"}
    ]
  }'

响应示例：

{
  "id": "chatcmpl-xxx",
  "object": "chat.completion",
  "model": "gpt-4o",
  "choices": [{
    "index": 0,
    "message": {
      "role": "assistant",
      "content": "量子计算是一种利用量子力学原理..."
    },
    "finish_reason": "stop"
  }],
  "usage": {
    "prompt_tokens": 25,
    "completion_tokens": 150,
    "total_tokens": 175
  }
}

流式输出（SSE）

设置 "stream": true 即可启用流式输出：

curl https://keys2api.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-你的KEY" \
  -d '{
    "model": "gpt-4o",
    "messages": [{"role": "user", "content": "讲一个笑话"}],
    "stream": true
  }'

聊天识图（Vision）

支持 GPT-4o、GPT-4o-mini 等视觉模型。通过 image_url 传入图片：

curl https://keys2api.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-你的KEY" \
  -d '{
    "model": "gpt-4o",
    "messages": [{
      "role": "user",
      "content": [
        {"type": "text", "text": "描述这张图片"},
        {"type": "image_url", "image_url": {"url": "https://example.com/image.jpg"}}
      ]
    }]
  }'

也支持 base64 格式：

{"type": "image_url", "image_url": {"url": "data:image/jpeg;base64,/9j/4AAQ..."}}

函数调用（Function Calling）

curl https://keys2api.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-你的KEY" \
  -d '{
    "model": "gpt-4o",
    "messages": [{"role": "user", "content": "北京今天天气怎么样？"}],
    "tools": [{
      "type": "function",
      "function": {
        "name": "get_weather",
        "description": "获取指定城市的天气",
        "parameters": {
          "type": "object",
          "properties": {
            "city": {"type": "string", "description": "城市名"}
          },
          "required": ["city"]
        }
      }
    }]
  }'

结构化输出（JSON Mode）

使用 response_format 强制返回 JSON：

{
  "model": "gpt-4o",
  "messages": [{"role": "user", "content": "列出三个编程语言及其特点"}],
  "response_format": {"type": "json_object"}
}

或使用 JSON Schema 精确控制输出格式：

{
  "model": "gpt-4o",
  "messages": [{"role": "user", "content": "提取信息"}],
  "response_format": {
    "type": "json_schema",
    "json_schema": {
      "name": "person_info",
      "strict": true,
      "schema": {
        "type": "object",
        "properties": {
          "name": {"type": "string"},
          "age": {"type": "integer"}
        },
        "required": ["name", "age"]
      }
    }
  }
}

可选值：low（快速）、medium（默认）、high（深度思考）。

系统 API

通过系统 API 管理你的密钥和账号信息。所有请求需要管理员权限的 token。

获取密钥列表

GET /api/token/
curl https://keys2api.com/api/token/ \
  -H "Authorization: Bearer sk-管理员KEY"

新增密钥

POST /api/token/
curl https://keys2api.com/api/token/ \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-管理员KEY" \
  -d '{
    "name": "我的密钥",
    "remain_quota": 5000000,
    "expired_time": -1,
    "unlimited_quota": false,
    "model_limits_enabled": false
  }'

获取账号信息

GET /api/user/self
curl https://keys2api.com/api/user/self \
  -H "Authorization: Bearer sk-管理员KEY"

修改密钥

PUT /api/token/
curl https://keys2api.com/api/token/ \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-管理员KEY" \
  -d '{
    "id": 1,
    "name": "新名称",
    "remain_quota": 10000000
  }'

删除密钥

DELETE /api/token/{id}
curl -X DELETE https://keys2api.com/api/token/1 \
  -H "Authorization: Bearer sk-管理员KEY"

Function Calling 完整示例

import json
from openai import OpenAI

client = OpenAI(api_key="sk-你的KEY", base_url="https://keys2api.com/v1")

tools = [{
    "type": "function",
    "function": {
        "name": "get_weather",
        "description": "获取指定城市的天气信息",
        "parameters": {
            "type": "object",
            "properties": {
                "city": {"type": "string", "description": "城市名称"}
            },
            "required": ["city"]
        }
    }
}]

# 第一步：让模型决定调用哪个函数
response = client.chat.completions.create(
    model="gpt-4o",
    messages=[{"role": "user", "content": "北京天气怎么样？"}],
    tools=tools,
)

tool_call = response.choices[0].message.tool_calls[0]
args = json.loads(tool_call.function.arguments)
print(f"模型请求调用 get_weather({args})")

# 第二步：执行函数（模拟）
def get_weather(city):
    return {"city": city, "temp": "25°C", "weather": "晴"}

result = get_weather(args["city"])

# 第三步：将结果返回给模型
response2 = client.chat.completions.create(
    model="gpt-4o",
    messages=[
        {"role": "user", "content": "北京天气怎么样？"},
        response.choices[0].message,
        {"role": "tool", "tool_call_id": tool_call.id, "content": json.dumps(result, ensure_ascii=False)},
    ],
    tools=tools,
)
print(response2.choices[0].message.content)

多轮对话

from openai import OpenAI

client = OpenAI(api_key="sk-你的KEY", base_url="https://keys2api.com/v1")

messages = [{"role": "system", "content": "你是一个有帮助的助手。"}]

while True:
    user_input = input("你: ")
    if user_input.lower() in ["exit", "quit", "退出"]:
        break

    messages.append({"role": "user", "content": user_input})

    response = client.chat.completions.create(
        model="gpt-4o",
        messages=messages,
    )

    reply = response.choices[0].message.content
    print(f"AI: {reply}\n")
    messages.append({"role": "assistant", "content": reply})

客户端配置教程

在各种工具和软件中使用 Keys2API。

Cursor

  1. 打开 Cursor → 设置（Settings）→ 模型（Models）
  2. 找到「OpenAI API Key」，填入：sk-你的KEY
  3. 找到「Override OpenAI Base URL」，填入：https://keys2api.com/v1
  4. 点击「Verify」验证连接
  5. 在模型列表中添加你需要的模型名（如 gpt-4o、claude-sonnet-4-6）

Claude Code

设置环境变量：

# Linux / macOS
export ANTHROPIC_BASE_URL=https://keys2api.com
export ANTHROPIC_API_KEY=sk-你的KEY

# Windows PowerShell
$env:ANTHROPIC_BASE_URL="https://keys2api.com"

或使用 OpenAI 兼容模式：

export OPENAI_BASE_URL=https://keys2api.com/v1

Cherry Studio

  1. 打开 Cherry Studio → 设置 → 模型服务
  2. 选择「OpenAI」或点击添加自定义服务商
  3. API Key 填入：sk-你的KEY
  4. API 地址填入：https://keys2api.com/v1
  5. 在模型列表中添加所需模型名称

配置 Claude 模型：在 Anthropic 服务商中，API 地址填 https://keys2api.com，Key 填你的 Key。

ChatBox

  1. 打开 ChatBox → 设置 → 模型
  2. 选择「OpenAI API」
  3. API Host 填入：https://keys2api.com/v1
  4. API Key 填入：sk-你的KEY
  5. 在模型 (Model) 中填入模型名，如 gpt-4o

Cline (VS Code)

  1. 在 VS Code 中安装 Cline 扩展
  2. 打开 Cline 设置 → API Provider 选择「OpenAI Compatible」
  3. Base URL 填入：https://keys2api.com/v1
  4. API Key 填入：sk-你的KEY
  5. Model 填入：claude-sonnet-4-6 或其他模型名

沉浸式翻译

  1. 打开沉浸式翻译设置 → 翻译服务
  2. 选择「OpenAI」
  3. API Key 填入：sk-你的KEY
  4. API 地址填入：https://keys2api.com/v1
  5. 模型填入：gpt-4o-mini（翻译推荐用 mini 省钱）

NextChat

  1. 打开 NextChat → 设置
  2. 选择「自定义接口」(Custom Endpoint)
  3. OpenAI Endpoint 填入：https://keys2api.com/v1
  4. API Key 填入：sk-你的KEY
  5. 选择或输入模型名

LobeChat

  1. 打开 LobeChat → 设置 → 语言模型
  2. 选择「OpenAI」
  3. API Key 填入：sk-你的KEY
  4. Proxy 地址填入：https://keys2api.com/v1
  5. 添加所需模型

Dify

  1. 在 Dify 中进入「设置」→「模型供应商」
  2. 选择「OpenAI-API-compatible」类型
  3. Model Name 填入：gpt-4o
  4. API Key 填入：sk-你的KEY
  5. API endpoint 填入：https://keys2api.com/v1

帮助中心

HTTP 状态码

状态码含义说明
200成功请求正常返回
400请求错误参数格式不正确，检查请求体
401未授权API Key 无效或未填写
403禁止访问密钥无权限访问该模型或分组
429请求过多超出速率限制（QPS），请降低频率
500服务器错误上游服务异常，请重试
502网关错误上游服务不可用
503服务不可用服务暂时不可用，请稍后重试

常见错误

额度不足

{
  "error": {
    "message": "当前分组额度已耗尽",
    "code": "insufficient_quota"
  }
}

解决：在控制台充值或更换有余额的密钥。

模型不存在

{
  "error": {
    "message": "该分组不支持该模型",
    "code": "model_not_found"
  }
}

解决：检查模型名是否正确，或更换支持该模型的分组。

超出速率限制

{
  "error": {
    "message": "请求过于频繁，请稍后再试",
    "code": "rate_limit_exceeded"
  }
}

解决：降低请求频率，或联系客服提升 QPS 限制。

思考字段说明

对于支持推理的模型（如 o3、DeepSeek-R1、Claude Thinking），返回结果中可能包含 reasoning_content 字段：

{
  "choices": [{
    "message": {
      "role": "assistant",
      "content": "最终答案",
      "reasoning_content": "让我思考一下... 首先..."
    }
  }]
}

reasoning_content 是模型的思考过程（链式思维），不计入输出 token 费用（部分模型除外，请参考价格页面）。
